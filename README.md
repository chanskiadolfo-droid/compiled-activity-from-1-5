# Activity 4 – CampusPass: Student Entry & Attendance Tracking System – Database Design, Reservation Management, and System Evaluation

## Description
This activity focuses on the database design, reservation management, and system evaluation process of the CampusPass – Student Entry & Attendance Tracking System. It explains how data is structured, stored, and managed to ensure accurate attendance tracking and efficient system performance.

The database is designed to securely store student information, entry logs, attendance records, and timestamps. Reservation and access management processes ensure that every student entry is properly recorded and validated to maintain system integrity.

## List and Explanation of the Activities Included

### Database Design
This activity involves creating and organizing the database structure used in the system. It includes tables for students, attendance logs, entry/exit records, and user accounts. The design ensures data consistency, security, and easy retrieval of records.

### Reservation / Entry Management
This explains how the system handles student entry and attendance tracking. It includes scanning ID cards, recording entry and exit times, validating user access, and storing attendance data in the database.

### System Development (SDLC Application)

**Planning Phase:**  
Requirements were gathered from students, faculty, and security staff to identify the need for a secure and efficient entry tracking system.

**Design Phase:**  
UML diagrams and database structures were created to visualize system flow, user interaction, and data storage.

**Implementation Phase:**  
The system was developed using programming languages such as Java/PHP and integrated with a database system like MySQL to handle attendance records.

**Testing Phase:**  
The system was tested to ensure accurate ID scanning, correct time logging, and proper database storage of attendance data.

## Reflection

### 1. What did you learn from creating database and system design?
I learned that proper database design is essential for organizing and managing large amounts of data efficiently. It ensures accuracy, reduces redundancy, and improves system performance.

### 2. Why is reservation or entry management important in a system?
It is important because it ensures that only authorized users can access the system, maintains accurate attendance records, and helps improve security and monitoring within the campus environment.
# Activity 5 – Integration App
## Description of the Repository
This repository contains the compiled activities for the Integration App for API Use project. The system is designed to demonstrate how different applications can communicate with external APIs to retrieve, send, and manage data efficiently. It focuses on system integration, real-time data handling, and improving application functionality through API usage.
The project highlights how APIs allow systems to connect with external services such as databases, web services, or third-party applications to enhance performance and automation.

## List and Explanation of the Activities Included

### API Integration Overview
This activity introduces the concept of API integration and explains how applications communicate with external systems to exchange data.

### API Request and Response Handling
This activity focuses on sending requests to APIs and processing responses, including JSON data handling and data parsing.

### System Integration Implementation
This explains how the application is connected with external APIs to retrieve or send data in real-time, improving system functionality.

### Error Handling and Validation
This activity covers managing API errors, handling failed requests, and ensuring that data received from APIs is valid and secure.

### Testing and Deployment
This includes testing API connections, verifying correct data flow, and ensuring the integration works properly before deployment.
